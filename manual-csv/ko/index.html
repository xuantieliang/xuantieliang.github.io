CSV 가져오기 안내

기존에 기록해 둔 수입과 지출을 매일 가계부로 옮겨 보세요. 앱에서 내보낸 CSV 파일은 그대로 사용할 수 있고, 다른 서비스의 데이터도 같은 형식으로 정리하면 가져올 수 있습니다. 수입·지출 내역과 이체 내역은 파일을 따로 만들어 하나씩 가져오세요.

처음 파일을 만든다면 앱에서 같은 종류의 CSV를 내보낸 뒤, 첫 줄의 열 이름은 유지하고 거래 내역을 채우는 방법이 가장 간편합니다. CSV로 옮길 수 있는 것은 거래 기록입니다. 가계부 전체를 복원하는 기능은 아니므로 사진, 예산, 앱 설정은 포함되지 않습니다.

가져오기 전에 확인하세요

가져온 내용을 한꺼번에 되돌리는 기능은 없습니다. 먼저 가계부를 백업해 주세요. 다른 앱에서 데이터를 옮길 때는 테스트용 가계부에 몇 건만 가져와 날짜, 금액, 계좌가 맞는지 확인한 뒤 나머지를 가져오는 것이 좋습니다.

파일 가져오기

  1. 데이터를 넣을 가계부로 전환한 뒤, 설정에서 CSV 가져오기를 엽니다.
  2. 화면의 ‘대상 장부’에 원하는 가계부가 표시되는지 확인합니다.
  3. CSV 파일 선택을 눌러 파일 하나를 고릅니다. 파일 이름은 자유롭게 정해도 됩니다. 앱이 열 이름을 보고 수입·지출 파일인지 이체 파일인지 구분합니다.
  4. 파일 확인이 끝나면 파일 이름, 유형, 기록 수를 살펴봅니다. 이 단계에서는 아직 가계부에 저장되지 않습니다.
  5. 가계부 이름이 표시된 가져오기 버튼을 누릅니다. 완료 후에는 처리한 기록 수와 태그 집계가 표시되며, 관련 계좌의 수입·지출 및 이체 합계도 갱신됩니다.

파일 확인을 통과했더라도 실제로 가져오는 과정에서 계좌 통화가 맞지 않거나 같은 이름의 계좌가 여러 개 발견될 수 있습니다. 가져오기에 실패하면 해당 파일의 변경 사항은 저장되지 않습니다. 문제를 수정한 뒤 파일을 다시 선택해 주세요.

CSV 파일 준비하기

  • 첫 줄에는 열 이름을, 두 번째 줄부터는 거래 내역을 입력합니다.
  • 파일은 UTF-8 인코딩으로 저장하는 것을 권장합니다.
  • 열을 쉼표로 구분하고 소수점에 마침표를 쓰는 ‘표준 형식’, 열을 세미콜론으로 구분하고 소수점에 쉼표를 쓰는 ‘유럽 형식’을 지원합니다. 한 파일 안에서는 같은 형식을 사용하세요.
  • 앱이 인식하지 못하는 추가 열은 건너뜁니다. 다만 수입·지출 전용 열과 이체 전용 열을 섞으면 파일 유형을 구분하지 못할 수 있습니다.

자주 발생하는 오류와 해결 방법

문제확인할 내용
CSV 유형을 확인할 수 없어요첫 줄에 열 이름이 있는지 확인하세요. 수입·지출 전용 열과 이체 전용 열을 한 파일에 섞지 마세요.
필수 열이 없다고 나와요대분류, 메모처럼 값을 비워 둘 수 있는 항목도 필수 열이면 첫 줄의 열 이름은 남겨 두어야 합니다. 열 이름이 위 표와 맞는지도 확인하세요.
멤버를 입력하라고 나와요모든 수입·지출 기록에 멤버 이름을 입력하세요. 기존 기록을 수정할 때도 필수이며, 공백만 입력하면 가져올 수 없습니다.
열이 중복되거나 용도를 확인할 수 없어요같은 항목을 한글 이름과 영문 이름으로 각각 넣지 않았는지 확인하세요. 이체의 통화 열은 ‘출금 통화’와 ‘입금 통화’로 구분합니다.
데이터 열 수가 맞지 않아요빠진 구분 기호가 없는지 확인하세요. 메모에 쉼표, 세미콜론, 줄바꿈이 들어가면 셀 전체를 큰따옴표로 감싸야 합니다.
날짜 형식이 올바르지 않아요연도는 서기 네 자리로 적고 월, 일, 입력한 시간이 실제로 존재하는지 확인하세요. Excel 날짜 일련번호나 불완전한 시간은 사용할 수 없습니다.
금액 형식이 올바르지 않아요표준 형식과 유럽 형식을 혼동하지 않았는지 확인하세요. 통화 기호, 자릿수를 나누는 공백, 수식은 제거합니다. 통화가 다른 이체의 입금 금액은 0일 수 없습니다.
수입/지출 구분이 올바르지 않아요수입·지출 또는 Income·Expense 등 지원하는 값을 사용하세요.
기존 계좌와 통화가 달라요CSV의 계좌 이름과 통화를 확인하세요. 필요한 경우 앱에서 원하는 통화의 계좌를 먼저 만드세요.
이름과 통화가 같은 계좌가 여러 개 있어요앱에서 계좌 이름을 서로 다르게 바꾼 뒤, CSV의 계좌 이름도 맞춰 주세요.
출금 계좌와 입금 계좌가 같아요서로 다른 계좌를 지정하세요. 영문 대소문자나 이름 앞뒤 공백만 바꾸면 같은 계좌로 인식됩니다.
카드 내역 반영일이 거래일보다 빨라요카드 내역 반영일을 거래 당일이나 그 이후 날짜로 바꾸세요.
태그 이름이나 개수가 조건에 맞지 않아요한 기록에 태그가 10개를 넘지 않는지, 이름이 너무 길지 않은지, 사용할 수 없는 문자나 보이지 않는 문자가 있는지 확인하세요.
파일이 비어 있거나 읽을 수 없어요CSV로 저장했는지, 문자 인코딩이 올바른지, 열 이름 아래에 거래가 한 건 이상 있는지 확인하세요. 클라우드에 있는 파일은 전체 내용을 내려받을 수 있어야 합니다.
다시 가져오니 기록이 중복됐어요UUID가 대상 가계부의 기존 기록과 일치하는지 확인하세요. 날짜와 금액이 같다는 이유만으로 기록을 합치거나 중복을 제거하지는 않습니다.
